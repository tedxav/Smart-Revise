# Python-based CLI for the "Quiz" section of https://smartrevise.online

## Setup:
1. Download the repo folder somehow (Either as a zip or through git)
2. Run main.py (**in the Smart-Revise folder**)
3. Follow the next instructions given by the program on how to input a past response's content and headers!
